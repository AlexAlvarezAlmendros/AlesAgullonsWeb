# Website UI Kit — masia-agullons

Interactive recreation of the Ales Agullons marketing site, composed from the design-system
primitives (no re-implemented components).

## Screens
- **Home** (`HomeScreen`) — hero, featured beers, specials band (dark brown), history teaser.
- **Cerveses** (`BeersScreen`) — full catalogue split into regulars + once-a-year specials.
- **Beer detail** (`BeerDetailScreen`) — label panel + tasting/pairing info + spec table.
- **Història** (`HistoriaScreen`) — timeline of the masia.

## Files
- `index.html` — entry; loads React UMD + Babel + `_ds_bundle.js`, then the scripts below.
- `data.js` — beer catalogue (`window.AGULLONS_BEERS`). ABV/IBU are **placeholders**.
- `chrome.jsx` — `Header`, `Footer`, `PhotoSlot` (warm placeholder for real photography).
- `screens.jsx` — `HomeScreen`, `BeersScreen`, `BeerDetailScreen`.
- `historia.jsx` — `HistoriaScreen`.
- `app.jsx` — view router + mount.

## Components used
`Button`, `Tag`, `Eyebrow`, `SpecList`, `BeerCard` from `window.AlesAgullonsDesignSystem_76dff6`.

## Notes / placeholders
- **Photography is placeholder** (`PhotoSlot`): toned blocks captioned with what belongs there
  (masia, barley fields, oak barrels, bottles on wood). Swap for real warm, golden-hour imagery.
- Copy is in **Catalan**, matching the brand's primary language. ABV/IBU values are illustrative.
- The compiled `_ds_bundle.js` is generated by the design-system compiler; previews require it.
