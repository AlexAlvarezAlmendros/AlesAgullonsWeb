## Quick reference
- **Brand:** Ales Agullons — rustic, rural, artisan Catalan brewery (Sant Joan de Mediona, Alt Penedès).
- **Tokens:** `styles.css` → `tokens/{colors,typography,spacing,base,fonts}.css`.
- **Voice:** warm first-person plural, Catalan-first, no emoji, ingredient- & pairing-led. See README "CONTENT FUNDAMENTALS".
- **Look:** parchment + ink, barley→stout beer spectrum, double-ruled label frames, letterpress press states, warm golden-hour photography. See README "VISUAL FOUNDATIONS".
- **Components:** `Button`, `Tag`, `Eyebrow`, `Input`, `SpecList`, `BeerCard` (window namespace `AlesAgullonsDesignSystem_76dff6`).
- **UI kit:** `ui_kits/website/` — interactive site recreation.
- **Fonts are Google-Fonts substitutes** (Sorts Mill Goudy / Bitter / Courier Prime) — see `tokens/fonts.css`.
