Typewriter-mono spec line/table for beer data — the brand's "icon" for product stats.

```jsx
<SpecList items={[{label:"ABV",value:"5.2%"},{label:"IBU",value:"38"},{label:"Format",value:"75 cl"}]} />
<SpecList layout="stack" onDark items={maltsAndHops} />
```

`layout`: `row` (inline) · `stack` (definition list). Set `onDark` over brown/stout grounds.
