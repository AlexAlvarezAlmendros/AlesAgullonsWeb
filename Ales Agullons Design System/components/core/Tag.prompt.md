Pill chip for beer styles, hop varieties, and food pairings. Tone signals the beer family.

```jsx
<Tag>Pale Ale</Tag>
<Tag tone="brown">Brown Ale</Tag>
<Tag tone="merlot" outline>Barrica</Tag>
```

Tones: `default` (gold), `brown`, `vine`, `merlot`, `plain`. Set `outline` for a hairline version. Text renders uppercase + tracked.
