Uppercase wide-tracked overline above section headings; set `rules` for the centered label-frame look.

```jsx
<Eyebrow>Cervesa artesana</Eyebrow>
<Eyebrow rules align="center" tone="gold">Edicions especials</Eyebrow>
```

Tones: `accent` (merlot), `gold`, `ink`, `paper` (on dark grounds). `align`: `left` · `center`.
